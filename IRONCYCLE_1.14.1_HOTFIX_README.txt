IronCycle 1.14.1 Quick Add Packaging Hotfix

1. Put apply_ironcycle_1_14_1_hotfix.py in the repository root beside main.py and constants.py.
2. Run: python apply_ironcycle_1_14_1_hotfix.py
3. Commit the modified main.py and constants.py.
4. Do not commit the generated *.bak files.
5. Build the APK normally.

The script:
- changes APP_VERSION from 1.14.0 to 1.14.1;
- keeps DATABASE_SCHEMA_VERSION at 11;
- adds WorkoutTrackerApp.exercise_exists_locally();
- replaces the missing exercise_exists(ex_name) call;
- creates local backups before writing;
- validates Python syntax and the final call path before changing files.

Acceptance check:
- Open Quick Add.
- Select Chest and Isolation.
- Type a new custom exercise.
- Tap Add.
- Confirm Create Exercise opens without NameError and retains Chest.
