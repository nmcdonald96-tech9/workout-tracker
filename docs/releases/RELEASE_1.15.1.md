# IronCycle 1.15.1

Cumulative Exercise Library release. Restores full per-exercise progression editing and adds Modify progression to the exercise card menu. Both routes use the same editor. Supports inherited/default mode, custom weight step, reduction steps, rep ceiling, reduction threshold, maximum progression RPE, maximum progression weight, effective-setting preview, simulation, reset defaults, and cache invalidation. Completed history remains unchanged. Schema 11.
