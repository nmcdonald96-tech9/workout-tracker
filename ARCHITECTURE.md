# IronCycle 1.9.0 Architecture Candidate

Behavioral reference: IronCycle 1.8.0, schema 10.

This candidate introduces `app`, `services`, `components`, `views`, and permanent `tests` boundaries. The Android-verified controller remains the compatibility shell while high-risk parts are moved incrementally behind tested interfaces. Session Context now consumes the centralized compatible Checkbox factory. Persistent muscle-group navigation remains operational and will not be folded into collapsible readiness/context information.
